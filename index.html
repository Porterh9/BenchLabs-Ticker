Get a free Finnhub API key

Finnhub is the live stock data provider your device polls for prices. A free account includes real-time US quotes.

  1. Go to finnhub.io/register and create a free account
  2. Your API key is shown on the Dashboard page after signing in
  3. Copy it and paste it below

Device address

Shown on the device's screen right now (something like 192.168.1.42). Your phone needs to be on the same WiFi network as the device for this step to work — not cellular, not a guest network.
